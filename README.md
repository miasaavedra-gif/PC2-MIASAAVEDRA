# Ruta Gamarra
Guía para comerciantes de galerías y ambulantes. Catálogo de orientación en Supabase y seguimiento local del avance por dispositivo. La aplicación no emite licencias ni certifica trámites.

Pruebas: `node --test`. Construcción: `node build.mjs`. Servir la carpeta `public/` mediante HTTP. Vercel ejecuta build y pruebas antes de publicar. La rama test se integra a main mediante PR.
