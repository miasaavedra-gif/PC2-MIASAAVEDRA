# Alerta Vecinal · PC2

Web comunitaria para registrar, ubicar y dar seguimiento a puntos críticos de salubridad en Lima Norte.

**Demo local:** `npm ci && npm test && npm run build`

Revisa `informe/INFORME_PC2.md` para el backlog, sprints, arquitectura, seguridad y guion de sustentación. Para conectar Supabase, usa la migración bajo `supabase/migrations` y configura `src/config.js`. No publiques claves privadas.

La demo incluye datos ilustrativos ficticios; la migración de producción no los inserta.

> Estado del despliegue cloud: consulta el informe.
